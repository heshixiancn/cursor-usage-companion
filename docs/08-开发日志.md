## 2026-10-15：本地研究沙盒 0.1

### 输入需求与范围处理

- 研究账号池、令牌、设备身份变化、额度耗尽和自动切换的架构；
- 将实验限定为本机合成系统，不连接 Cursor，不注册真实账号，不修改系统机器标识，不影响第三方计费；
- 保留需求、安全边界、架构决策、测试与开发过程记录。

### 完成内容

- 新增独立目录 `research-lab`；
- 实现批量合成账号、本地令牌签发、到期检查、撤销、虚拟设备创建/轮换；
- 实现额度消费、超额 429、下一模拟账号选择和账期重置；
- 实现本地随机管理密钥和 SQLite 审计日志；
- 固定监听 `127.0.0.1`，不提供公网绑定配置；
- 合成身份、令牌和设备分别使用 `.invalid`、`lab_tok_`、`vdev_` 隔离标记；
- 数据库只保存令牌 SHA-256，不保存明文。
- 根地址提供无需密钥的中文状态页，避免浏览器直接打开时误认为服务故障。

### 技术调整

- 初版计划使用 Rust HTTP 框架，但构建环境无法稳定下载新增依赖；
- 改为 Node.js 24 内置 HTTP 与 SQLite，实现不依赖第三方包的本地服务；
- `node:sqlite` 当前会提示实验性 API，适合本地研究；正式部署前需替换为稳定驱动并重新审计。

## 2026-10-16：桌面研究控制台

### 完成内容

- 桌面侧栏新增“研究沙盒”；
- 新增服务状态、模拟账号总量、总额度、虚拟设备和当前令牌概览；
- 支持生成 1–20 个合成账号并设置模拟额度；
- 支持创建和轮换 `vdev_` 应用内部虚拟设备；
- 支持为指定合成账号签发、到期和撤销 `lab_tok_`；
- 支持消耗 10/25 点模拟额度；
- 收到本地 429 后自动选择下一可用模拟账号；
- 支持主动切换账号、重置全部模拟用量和查看最近审计记录；
- 浏览器预览使用不可操作的合成示例，避免读取本机管理密钥。

### 安全设计

- WebView 不能提交主机、端口或 URL；
- Rust 只允许预定义操作映射到 `127.0.0.1:17840` 的固定路径；
- 管理密钥只在 Rust 层读取和发送，不返回前端；
- 仅接受由字母、数字和下划线组成的 `lab_admin_` 与 `lab_tok_`；
- 当前令牌只保存在页面运行内存，关闭或刷新后消失；
- 未增加外部网络域名、CORS 或通用代理能力。
