## 阶段 3：官方用量同步

前提：目标服务商提供稳定、公开且允许使用的接口。

- Provider 插件接口；
- 最小只读授权；
- 手动刷新与可控定时刷新；
- 同步错误、限流和撤销授权；
- 服务商数据与手动数据来源区分；
- 网络请求审计和隐私文档更新。

如果 Cursor 没有公开用量接口，继续保留手动录入，不使用内部接口替代。

- 发布渠道、版本策略和支持流程。

## 主要风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 缺少公开用量接口 | 无法自动同步 | 手动记录作为稳定主路径 |
| Keychain 签名身份变化 | 升级后访问提示 | 早期固定签名身份并专项测试 |
| Windows 企业组策略 | 凭证库或 WebView 受限 | 提供诊断和明确错误，不降级为明文 |
| Tauri/系统更新 | 构建或权限变化 | lockfile、CI 矩阵、定期依赖升级 |
| 产品被误解为绕过工具 | 品牌与合规风险 | 名称、界面、文档持续强调边界 |
