# Windows 与 macOS 跨平台适配方案

版本：0.1  
日期：2026-10-15

## 1. 支持矩阵

| 项目 | Windows | macOS |
|---|---|---|
| 最低版本 | Windows 10 | macOS 12 |
| 首发架构 | x86_64 | arm64、x86_64 |
| 后续架构 | ARM64 | Universal 2 |
| WebView | Edge WebView2 | WKWebView |
| 安全存储 | Credential Manager | Keychain |
| 安装包 | MSI/NSIS EXE | APP/DMG |
| 正式签名 | Authenticode | Developer ID + Notarization |
| 研究服务 | Node.js 24+，仅本机开发/研究 | Node.js 24+，仅本机开发/研究 |

## 2. 共用层

- 页面、样式、表单与状态展示完全共用；
- Rust 数据模型、输入校验和 JSON 持久化共用；
- 系统凭证库通过 `keyring` 统一接口；
- 平台差异只留在安装检测、构建和签名环节；
- 所有时间以 UTC 保存、按本地时区显示。
- 研究控制台和白名单桥接逻辑共用；研究服务不进入正式用户默认启动流程。

## 3. macOS

### Cursor 检测

- `/Applications/Cursor.app`
- `~/Applications/Cursor.app`

只检查路径是否存在，不读取应用内容。

### Keychain

- service：`com.githubdiscover.usagecompanion`
- account：连接 UUID
- 首次写入可能出现系统钥匙串授权提示；
- 正式签名后 Keychain 访问身份更稳定，开发签名与生产签名切换需要专项回归。

### 构建

- Apple Silicon：`aarch64-apple-darwin`
- Intel：`x86_64-apple-darwin`
- Universal：分别编译后合并，或使用 Tauri 对应 target；
- 最低系统版本在 `tauri.conf.json` 设置为 12.0。

### 发布

1. 使用 Developer ID Application 签名；
2. 启用 Hardened Runtime；
3. 上传 Apple Notary Service；
4. stapler 附加公证票据；
5. 在干净 macOS 账户验证 Gatekeeper；
6. 发布 DMG 与 SHA-256。

## 4. Windows

### Cursor 检测

- `%LOCALAPPDATA%\Programs\cursor\Cursor.exe`
- `%LOCALAPPDATA%\Programs\Cursor\Cursor.exe`
- `%ProgramFiles%\Cursor\Cursor.exe`

只读检查，不访问 Cursor 用户数据目录。

### Credential Manager

- 通过 Windows 原生 Credential Store 保存；
- 以连接 UUID 作为用户名/条目标识；
- 不写注册表明文、不写 `.env`；
- 企业设备可能受组策略影响，需要明确错误提示。

### 构建与发布

- 使用 Windows 构建机生成 MSI/NSIS；
- 正式版本使用受信任代码签名证书；
- 建议同时发布 SHA-256；
- 检查 WebView2 运行时策略；
- 在标准用户、中文用户名路径和企业组策略环境测试。

## 5. CI 建议

建立矩阵构建：

- `macos-14`：arm64；
- `macos-13` 或 Intel 构建机：x86_64；
- `windows-2022`：x86_64；
- 后续增加 Windows ARM64。

CI 阶段：前端类型检查 → 前端构建 → Rust 格式检查 → Clippy → 单元测试 → 平台打包 → 签名/公证 → 哈希与 SBOM。

密钥、证书与 Apple 凭证只放 CI Secret，不写入仓库和构建日志。

## 6. 平台验收重点

### macOS

- Keychain 首次保存、覆盖、删除；
- Apple Silicon 与 Intel 启动；
- 应用移入 Applications 后仍可访问既有凭证；
- 公证后无“无法验证开发者”提示。

### Windows

- 标准用户无需管理员权限；
- Credential Manager 保存与删除；
- MSI/EXE 安装、升级和卸载；
- 中文用户名和长路径；
- WebView2 缺失或被管控时的提示。

### 研究沙盒

- Node.js 24 内置 SQLite 在两平台都需要专项验证；
- 服务固定监听 IPv4 `127.0.0.1`，不依赖主机名解析；
- 开发环境通过项目内 `.lab-data` 定位管理密钥；
- 可分发版本如需包含研究功能，应先设计稳定数据库驱动、服务生命周期和应用数据目录迁移；
- 未完成上述工作前，研究服务不随正式安装包自动启动。
