# 安全与合规设计

版本：0.1  
日期：2026-10-15

## 1. 安全目标

1. API Key 不进入普通文件、前端快照、日志和错误信息；
2. 应用只操作用户明确添加的凭证；
3. 默认不联网，不把用量和账号备注上传；
4. 不改变 Cursor 身份、设备或计费状态；
5. 任何未来同步功能都必须可解释、可撤销、最小权限。

## 2. 数据分类

| 数据 | 等级 | 存储 | 是否返回前端 |
|---|---|---|---|
| API Key/访问凭证 | 高敏感 | 系统凭证库 | 否 |
| 连接 UUID | 普通 | JSON | 是 |
| 显示名称、账号备注 | 中等 | JSON | 是 |
| 用量、阈值、账期 | 普通 | JSON | 是 |
| Cursor 安装路径 | 本机环境 | 不持久化 | 是 |
| 操作系统与架构 | 本机环境 | 不持久化 | 是 |
| 研究沙盒管理密钥 | 本机敏感 | `research-lab/.lab-data` | 否 |
| `lab_tok_` 模拟令牌 | 本机实验 | 服务端仅存哈希，桌面端仅内存 | 签发时返回当前页面 |
| 合成账号、虚拟设备、审计 | 本机实验 | 独立 SQLite | 是 |

账号备注可能包含邮箱，因此界面应提醒用户不要填写密码。团队版如上传备注，需要单独的隐私评估。

## 3. 凭证生命周期

### 创建

- 前端密码输入框使用 `autocomplete="new-password"`；
- 通过 Tauri IPC 一次性传给 Rust；
- Rust 写入 Keychain/Credential Manager；
- 元数据只记录 `secret_saved=true`；
- 页面重新渲染，原输入框被销毁。

### 使用

MVP 不读取密钥执行远端请求，因此没有从安全存储取出并驻留内存的流程。未来 Provider 使用密钥时，只允许在 Rust 层短期读取，并避免转换为可日志化结构。

### 删除

- 用户确认后删除凭证条目和元数据；
- 正式版需要对“不存在”和“删除失败”给出不同处理；
- 卸载时默认不自动清除系统凭证，需提供单独的“清除全部本地数据”操作和明确确认。

## 4. 威胁模型

### T-01 普通配置文件泄漏

风险：备份、同步盘或其他本地用户读到 JSON。  
措施：JSON 不包含密钥，只含备注和用量；文档明确数据位置和内容。

### T-02 前端脚本读取密钥

风险：WebView 或开发者工具调用命令获取密钥。  
措施：后端不暴露读取密钥命令，返回结构不含 secret 字段，CSP 限制外部脚本。

### T-03 本地 IPC 滥用

风险：恶意页面试图调用 Tauri 命令。  
措施：只给 `main` 窗口默认能力，不加载远端网页；不开放本地 HTTP 端口；保持严格 CSP。

### T-04 路径或输入注入

风险：恶意备注、服务商值或连接 ID 影响文件和系统凭证。  
措施：服务商使用白名单，长度限制，数据文件路径完全由应用控制，连接 ID 由 UUID 生成。

### T-05 供应链风险

风险：桌面依赖或更新包被替换。  
措施：提交 lockfile、固定直接前端依赖、正式发布签名、公证、生成 SHA-256 和 SBOM，自动更新必须校验签名。

### T-06 本机已被攻陷

风险：具有用户权限的恶意程序读取进程内存或调用系统凭证库。  
措施：本应用不能在已被攻陷的主机上提供绝对保护；减少密钥驻留时间、不回显、不记录，并向用户说明边界。

### T-07 研究桥接被扩展为通用代理

风险：前端提交任意 URL，借桌面权限访问其他本机或远端服务。  
措施：Rust 使用枚举映射固定方法和路径，主机与端口编译期固定为 loopback；不接受 URL、主机或端口参数。

### T-08 本地网页跨站调用研究接口

风险：浏览器中的第三方网页尝试操作本地模拟数据。  
措施：研究服务不启用 CORS，管理接口强制 `X-Lab-Key`；密钥不进入网页或 URL，桌面 WebView 通过 Rust 桥接调用。

## 5. 权限设计

- 不申请管理员/root 权限；
- 不修改系统代理、DNS、hosts、证书和防火墙；
- 不注入其他进程；
- 正式桌面核心不监听端口；独立研究服务仅监听 `127.0.0.1`；
- 不读取 Cursor 数据库、聊天记录和认证文件；
- 不访问浏览器 Cookie；
- 文件写入仅限应用数据目录；
- 系统凭证库条目使用应用专属 service 名。

## 6. 明确禁止的功能

以下需求即使技术上可行，也不进入本产品：

- 免费账号批量注册、验证码平台接入；
- 共享账号或令牌池；
- 自动轮换账号规避用量；
- 修改 `cursorAuth/*`、telemetry ID 或设备指纹；
- 拦截、改写 Cursor 的 HTTP/1、HTTP/2 或 fetch 请求；
- 绕过地区限制、订阅、计费、风控；
- 将产品包装为 Cursor 官方工具。

## 7. 合规呈现

- 产品名称和图标不使用 Cursor 商标外观；
- 界面说明“检测 Cursor”而非“官方集成”；
- README 和产品内均展示安全边界；
- 未来接入服务商时遵守其公开文档和授权范围；
- 对用户数据收集保持默认最少化。
