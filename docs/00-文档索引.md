## 文档维护约定

1. 产品范围变化先更新需求文档，再修改代码。
2. 涉及密钥、联网、自动化或第三方账号的变更必须更新安全文档。
3. 平台专用功能必须同时记录 Windows 与 macOS 的行为差异。
4. 已做出的关键技术选择不直接覆盖，追加到架构决策记录中。
5. 每次交付记录完成项、验证结果和未完成项，避免把计划写成已实现。
