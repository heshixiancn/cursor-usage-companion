# 本地研究沙盒需求与边界

版本：0.1（已实现）  
日期：2026-10-15

## 1. 研究目标

在不连接 Cursor、不给第三方服务造成成本或风险的前提下，复现下列系统设计问题：

1. 合成账号池如何建模、排序和分配；
2. 短期令牌如何签发、保存和撤销；
3. 应用内部虚拟设备 ID 如何创建与轮换；
4. 额度如何记账、拒绝超额请求并返回 429；
5. 客户端如何根据用量选择下一个模拟账号；
6. 账期重置和所有关键行为如何审计。

## 2. 隔离边界

### 必须满足

- 只监听 IPv4 loopback `127.0.0.1`；
- 不提供配置项改为公网地址；
- 不依赖外部 HTTP 客户端；
- 合成邮箱全部使用 `example.invalid`；
- 模拟令牌全部使用 `lab_tok_`；
- 虚拟设备全部使用 `vdev_`；
- API 响应包含 `environment=local-research-lab`；
- 账号、设备、额度和审计只存本地 SQLite；
- 管理接口要求本地随机密钥；
- 数据库只存令牌哈希。

### 明确禁止

- Cursor 域名、接口、Cookie、Token 或账号；
- 真实邮箱注册、验证码接收或第三方登录；
- 修改系统 UUID、MAC、MachineGuid、硬件序列号；
- 修改 Cursor 安装文件、状态库或网络请求；
- 代理、隧道、流量转发；
- 真实付款、订阅或额度规避。

## 3. 功能需求

### LAB-01 合成账号

- 每批生成 1–20 个；
- 每个账号有独立额度、已用量和状态；
- 邮箱不可投递；
- 支持列表查询。

### LAB-02 本地令牌

- 绑定合成账号和虚拟设备；
- 明文只在签发响应出现一次；
- 数据库存储 SHA-256；
- 令牌有真实到期时间并支持主动撤销；
- 非 `lab_tok_` 令牌必须拒绝。

### LAB-03 虚拟设备

- 创建应用内部虚拟设备；
- 轮换生成新 ID 并增加 generation；
- 轮换记录 previous ID；
- 不调用任何系统硬件接口。

### LAB-04 额度记账

- 正常消耗原子更新；
- 超额不修改已用量；
- 超额返回 429 与 `should_switch=true`；
- 支持查询剩余和百分比。

### LAB-05 模拟切换

- 排除当前账号；
- 只选择 active 且有剩余额度的账号；
- 优先选择使用比例更低的账号；
- 为同一虚拟设备签发新令牌；
- 无可用账号时返回明确错误。

### LAB-06 账期与审计

- 可重置单个或全部模拟账号；
- 创建、签发、消耗、拒绝、轮换、切换、重置均写审计；
- 审计接口最多返回 500 条。

## 4. 威胁模型

- 本机其他进程调用管理 API：随机 `X-Lab-Key`；
- 网页跨站调用：不启用 CORS；
- 沙盒误连公网：地址在代码中固定为 loopback；
- 令牌数据库泄漏：只保存哈希；
- 沙盒令牌被误用于外部服务：专用前缀且没有外部服务识别；
- 合成邮箱误发送：使用 RFC/IANA 保留的 `.invalid` 顶级域；
- 数据误当成生产数据：每个响应带环境标记。

## 5. 验收标准

- 单元测试覆盖账号、令牌哈希、额度拒绝、设备轮换、账号切换与账期重置；
- 健康检查明确返回外网关闭、仅合成身份；
- 非本地实验令牌被拒绝；
- 超额消耗返回 429 且原用量不变；
- 代码库中不出现 Cursor API 或真实账号注册实现；
- JavaScript 语法检查和全部 14 项自动化测试通过。

## 6. 桌面控制台

- 页面只提交预定义操作名，不能指定网络目标；
- 管理密钥由 Rust 核心读取，不暴露给 WebView；
- 支持生成账号、设备轮换、令牌签发/撤销、额度消耗、自动切换、重置和审计；
- 浏览器预览只展示不可操作的合成示例；
- 当前令牌不做持久化，应用关闭后即丢失；
- 实际桥接流程必须覆盖 429 与自动切换。
