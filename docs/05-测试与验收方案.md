# 测试与验收方案

版本：0.1  
日期：2026-10-15

## 1. 测试分层

### 静态检查

- TypeScript 严格类型检查；
- Vite 生产构建；
- `cargo fmt --check`；
- `cargo clippy -- -D warnings`；
- Tauri 配置解析和权限检查。

### Rust 单元测试

- 阈值顺序校验；
- 严重阈值上限；
- 用量负数、零额度、非有限数；
- 支持的服务商与凭证最小长度；
- 平台候选路径不为空；
- 数据文件名与敏感存储分离。

### 集成测试

- 首次启动创建默认数据；
- 保存连接后 JSON 不含密钥；
- 系统凭证库存在对应条目；
- 删除连接后凭证与元数据均消失；
- 数据文件损坏时给出可理解错误；
- 多次快速保存不会产生重复或损坏。

### UI 验收

- 概览、连接、设置三页切换；
- 空状态与有数据状态；
- 添加连接与更新用量弹窗；
- 70%/90% 阈值状态；
- 长名称、长备注和中文字符；
- 900×650 最小窗口无关键内容遮挡；
- 键盘聚焦、表单标签和错误提示可用。

### 研究沙盒自动化测试

- 非法管理密钥返回 401；
- 只生成 `.invalid` 合成账号；
- 数据库只保存 `lab_tok_` 令牌哈希；
- 撤销后的模拟令牌不能继续使用；
- 合法消耗原子更新余额；
- 超额消耗返回 429 且用量不变；
- 虚拟设备轮换保留代际关系；
- 可选择下一可用模拟账号并签发本地令牌；
- 单个和全部账期重置；
- 关键操作进入审计记录；
- 健康检查声明外网关闭和仅合成身份。
- 根地址显示无需密钥的中文运行状态页。

## 3. 安全测试

使用专门的假密钥 `sk-test-do-not-use-...`：

1. 保存后搜索应用数据目录、日志和构建输出；
2. 检查 Tauri IPC 返回值；
3. 检查界面 DOM 和浏览器存储；
4. 删除连接后验证系统凭证不可获取；
5. 确认错误提示不包含输入值；
6. 检查 CSP 与能力文件没有远端页面或不必要权限。
