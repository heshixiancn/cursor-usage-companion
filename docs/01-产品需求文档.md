# 产品需求文档：用量伙伴 MVP

版本：0.1  
日期：2026-10-15  
目标平台：Windows 10/11、macOS 12+  
产品性质：管理用户自有 AI 凭证和用量的本地桌面工具

## 1. 背景

AI 编程工具的用量分散在多个服务商和账期中。用户需要一个低学习成本的桌面界面，记录本周期使用情况、集中保管自己拥有的 API Key，并在接近预算或额度上限时获得提醒。

原始调研对象通过账号池、内部令牌替换和机器标识处理实现所谓“自动续杯”。该方向存在明显的账号、凭证、服务条款与计费规避风险。本产品只保留“用量可视化、授权凭证管理、阈值提醒、跨平台体验”这些正当需求。

## 2. 产品目标

### 2.1 MVP 目标

- 提供 Windows 与 macOS 一致的桌面体验；
- 让用户在一分钟内完成一次用量记录；
- 把用户自有 API Key 存入操作系统安全凭证库；
- 在界面中清楚显示已用比例、剩余额度和提醒状态；
- 检测本机是否安装 Cursor，但不修改其内部文件或登录状态；
- 形成可扩展的官方用量同步与系统通知基础。
- 提供与正式功能隔离的本地合成研究沙盒，用于验证账号、令牌、设备和额度状态机。

### 2.2 非目标

- 不自动注册、购买、共享或出租第三方账号；
- 不提供真实第三方账号池或可用于外部服务的访问令牌分发；
- 不修改 Cursor 的访问令牌、状态数据库或安装文件；
- 不重置、伪造或隐藏机器标识；
- 不绕过订阅、计费、限额、风控或地区限制；
- 不在服务商没有公开授权接口时抓取其内部接口。

## 3. 目标用户

### 3.1 个人开发者

同时使用多个 AI 服务，希望掌握当期用量，避免突然超额或中断。

### 3.2 小型团队负责人

希望为自有密钥添加用途备注，建立统一的预算提醒习惯，但不需要完整的企业成本平台。

### 3.3 技术支持人员

需要快速确认用户的操作系统、Cursor 是否安装、用量记录是否更新，而无需接触用户的完整密钥。

## 4. 核心用户故事

1. 作为用户，我希望看到当前用量百分比和剩余额度，以便快速判断是否需要调整使用计划。
2. 作为用户，我希望安全保存自己的 API Key，避免写在文本文件或聊天记录里。
3. 作为用户，我希望设置普通和严重两级阈值，以便提前处理预算。
4. 作为用户，我希望删除一个连接时同时删除系统凭证库中的密钥。
5. 作为 macOS 用户，我希望密钥保存在 Keychain 中。
6. 作为 Windows 用户，我希望密钥保存在 Credential Manager 中。
7. 作为用户，我希望应用明确告诉我哪些行为不会执行，避免误以为它能绕过官方限制。
8. 作为开发研究者，我希望用不可投递身份和本地专用令牌观察 429、自动切换与重置，同时确保实验不会连接第三方服务。

## 5. 功能需求

### F-01 应用概览

- 显示已使用、总额度、剩余额度、使用比例；
- 显示普通、预警、严重三种状态；
- 显示数据来源和最近更新时间；
- 显示当前操作系统、架构、系统凭证库状态和 Cursor 检测结果。

验收：输入 32.4/100 时显示 32%、剩余 67.6，状态依据阈值正确变化。

### F-02 用量记录

- 用户可填写已使用、总额度、单位和可选重置时间；
- 数据保存到应用数据目录；
- 后端重新生成更新时间并强制标记数据来源为“手动录入”；
- 非数字、负数、零总额度必须拒绝。

### F-03 授权连接

- 支持 OpenAI、Anthropic、Google AI、Cursor 自有密钥和其他服务；
- 保存显示名称、服务商和账号备注；
- API Key 只写入系统安全凭证库；
- 普通 JSON 数据中只保存连接 ID 和非敏感元数据；
- 前端保存后不回显完整 API Key；
- 删除连接时删除对应系统凭证。

### F-04 提醒设置

- 普通阈值范围 1%–98%；
- 严重阈值范围 2%–100%；
- 普通阈值必须低于严重阈值；
- 预留 5、15、30、60 分钟检查间隔；
- 预留系统通知开关。

### F-05 Cursor 环境检测

- macOS 检查 `/Applications/Cursor.app` 与用户应用目录；
- Windows 检查用户本地程序目录和 Program Files 常见路径；
- 只读检查，不启动、不修改 Cursor。

### F-06 跨平台发布

- macOS 提供 Apple Silicon 与 Intel 构建能力，正式发布支持签名和公证；
- Windows 提供 x64 安装包，后续增加 ARM64；
- 平台安装包在对应系统或可信 CI 构建机上生成。

### F-07 本地研究沙盒

- 桌面侧栏提供独立研究入口，与自有凭证和正式用量数据隔离；
- 只使用 `.invalid` 合成身份、`lab_tok_` 本地令牌和 `vdev_` 虚拟设备；
- 支持生成模拟账号、签发/撤销令牌、模拟额度消耗、429、账号切换、账期重置和审计；
- Rust 桥接固定连接 `127.0.0.1:17840`，前端不能指定网络目标；
- 管理密钥不得返回 WebView，当前模拟令牌不得持久化；
- 浏览器预览只展示不可操作的合成数据。

## 6. 非功能需求

### 安全

- 密钥不得进入日志、普通配置、错误信息或前端状态快照；
- 本地命令必须验证所有输入；
- 默认不联网；
- 不申请管理员权限；
- 内容安全策略只允许应用自身资源和 Tauri IPC。

### 性能

- 冷启动目标小于 3 秒；
- 本地保存操作目标小于 300 毫秒；
- 空闲状态不持续占用 CPU；
- 应用数据量按少于 500 个连接设计。

### 可用性

- 主要操作不超过两层页面；
- 密钥保存位置必须使用非技术语言解释；
- 错误提示不暴露密钥或底层堆栈。

## 7. MVP 成功标准

- 前端生产构建通过；
- Rust 单元测试全部通过；
- macOS 本机可启动并完成保存/删除凭证流程；
- Windows CI 或 Windows 真机完成相同流程；
- 普通数据文件中搜索不到测试 API Key；
- 安全边界在产品界面和 README 中均可见。

## 8. 后续候选需求

- 系统原生通知；
- 用户主动授权的官方只读用量同步；
- 本地加密备份与恢复；
- 多预算项目和月度趋势；
- 自动更新、签名、公证和崩溃诊断；
- 团队版的角色、审计和集中策略。
